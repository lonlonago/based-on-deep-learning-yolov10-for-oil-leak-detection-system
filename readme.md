# Based on deep learning YOLOv10 for oil leak detection system

## Body

This project aims to utilize the YOLOv10 object detection algorithm to construct an efficient and accurate oil leak detection system. The system can detect oil leakage areas in images or videos in real-time, and output detection results. By training and optimizing the model, the system can accurately identify oil leaks in complex backgrounds, meeting the needs of environmental monitoring and industrial safety.
